# YouTube Clone

A simple YouTube homepage clone built using **HTML** and **CSS**.

## Features

* Responsive video grid
* Fixed header and sidebar
* Video thumbnails and channel information
* Hover effects and tooltips
* Mobile-friendly layout using media queries

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Grid

## Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open `index.html` in your browser.

## Purpose

This project was created to practice responsive web design and improve HTML/CSS skills.
